## 🎯 PUNTOS CLAVE QUE DEBES MEMORIZAR

### Los "BIG 3":

```
1. ORDEN ALTERNADO (Deadlock Prevention)
   └─ Pares: right fork primero
   └─ Impares: left fork primero
   └─ Rompe ciclo de espera

2. 4 MUTEXES (Sincronización)
   └─ print_mtx: outputs
   └─ meal_mtx: datos
   └─ stop_mtx: parada
   └─ forks[n]: recursos

3. SMART_SLEEP (Interrupción limpia)
   └─ Chequea !should_stop() cada 200μs
   └─ Permite reacción inmediata
   └─ Termina cuando boss requiera
```

### Las "5 Funciones Críticas":

```
1. philo_routine()    → Qué hace cada filósofo
2. boss_routine()     → Qué hace el supervisor
3. take_forks()       → Cómo evita deadlock
4. smart_sleep()      → Cómo se interrumpe
5. init_program()     → Cómo se inicializa con error handling
```
